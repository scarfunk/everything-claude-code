# /learn - 재사용 가능한 패턴 추출

현재 세션을 분석하고 스킬로 저장할 가치가 있는 패턴을 추출합니다.

## 트리거

세션 중 비사소한 문제를 해결했을 때 언제든 `/learn`을 실행하세요.

## 추출 대상

다음을 찾아보세요:

1. **오류 해결 패턴**
   - 어떤 오류가 발생했나?
   - 근본 원인은 무엇이었나?
   - 무엇이 해결했나?
   - 유사한 오류에 재사용 가능한가?

2. **디버깅 기법**
   - 명확하지 않은 디버깅 단계
   - 효과가 있었던 도구 조합
   - 진단 패턴

3. **해결책**
   - 라이브러리 특이점
   - API 제한사항
   - 버전별 수정

4. **프로젝트별 패턴**
   - 발견된 코드베이스 규칙
   - 내린 아키텍처 결정
   - 통합 패턴

## 출력 형식

`~/.claude/skills/learned/[패턴-이름].md`에 스킬 파일 생성:

```markdown
# [설명적 패턴 이름]

**추출일:** [날짜]
**컨텍스트:** [이것이 적용되는 경우에 대한 간략한 설명]

## 문제
[이것이 해결하는 문제 - 구체적으로]

## 해결책
[패턴/기법/해결책]

## 예시
[해당되는 경우 코드 예시]

## 사용 시점
[트리거 조건 - 이 스킬을 활성화해야 하는 것]
```

## 프로세스

1. 세션에서 추출 가능한 패턴 검토
2. 가장 가치있고 재사용 가능한 인사이트 식별
3. 스킬 파일 초안 작성
4. 저장 전 사용자에게 확인 요청
5. `~/.claude/skills/learned/`에 저장

## 참고사항

- 사소한 수정은 추출하지 마세요 (오타, 간단한 구문 오류)
- 일회성 이슈는 추출하지 마세요 (특정 API 장애 등)
- 향후 세션에서 시간을 절약할 패턴에 집중
- 스킬을 집중적으로 유지 - 스킬당 하나의 패턴

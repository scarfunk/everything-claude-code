# 빌드 및 수정

TypeScript 및 빌드 오류를 점진적으로 수정:

1. 빌드 실행: npm run build 또는 pnpm build

2. 오류 출력 파싱:
   - 파일별 그룹화
   - 심각도별 정렬

3. 각 오류에 대해:
   - 오류 컨텍스트 표시 (앞/뒤 5줄)
   - 이슈 설명
   - 수정안 제안
   - 수정 적용
   - 빌드 재실행
   - 오류 해결 확인

4. 다음 경우 중지:
   - 수정이 새로운 오류를 도입
   - 3번 시도 후에도 같은 오류 지속
   - 사용자가 일시 중지 요청

5. 요약 표시:
   - 수정된 오류
   - 남은 오류
   - 도입된 새 오류

안전을 위해 한 번에 하나의 오류만 수정하세요!

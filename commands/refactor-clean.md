# 리팩토링 정리

테스트 검증과 함께 데드 코드를 안전하게 식별하고 제거:

1. 데드 코드 분석 도구 실행:
   - knip: 사용하지 않는 익스포트 및 파일 찾기
   - depcheck: 사용하지 않는 의존성 찾기
   - ts-prune: 사용하지 않는 TypeScript 익스포트 찾기

2. .reports/dead-code-analysis.md에 포괄적 보고서 생성

3. 심각도별 발견사항 분류:
   - 안전: 테스트 파일, 사용하지 않는 유틸리티
   - 주의: API 라우트, 컴포넌트
   - 위험: 설정 파일, 메인 진입점

4. 안전한 삭제만 제안

5. 각 삭제 전:
   - 전체 테스트 스위트 실행
   - 테스트 통과 확인
   - 변경 적용
   - 테스트 재실행
   - 테스트 실패 시 롤백

6. 정리된 항목 요약 표시

테스트를 먼저 실행하지 않고 코드를 삭제하지 마세요!

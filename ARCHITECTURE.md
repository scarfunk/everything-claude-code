## 핵심 포인트

| 관계 | 설명 |
|------|------|
| **Command → Agent** | 1:1 매핑으로 호출 |
| **Agent → Skill** | 도구/패턴 참조 |
| **Rules** | Agent/Skill에서 참조되는 규칙 |
| **Commands 간 연계** | `/plan` → `/tdd` → `/e2e` → `/verify` → `/code-review` |

---

## 컴포넌트 역할

### Commands (명령어)
사용자가 직접 호출하는 슬래시 명령어. Agent를 트리거합니다.

### Agents (에이전트)
특정 도메인 전문가. 복잡한 작업을 수행하고 Skill을 참조합니다.

### Skills (스킬)
재사용 가능한 패턴과 가이드라인. Agent가 참조하는 도구 모음입니다.

### Rules (규칙)
프로젝트 전반에 적용되는 규칙. `.claude/rules/`에 배치하면 자동 로드됩니다.

### Contexts (컨텍스트)
작업 모드별 설정. 개발/리서치/리뷰 등 상황에 맞는 지침을 제공합니다.
